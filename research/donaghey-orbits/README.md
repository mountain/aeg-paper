# Donaghey's transformation — orbit verification

Finite computation accompanying the research note
`notes/analysis-and-calculus/27-mirror-reversal-tree-layer.md` (OQ-098.1).

## What is verified

`verify_orbits.py` implements Donaghey's transformation `τ` on plane planted
cubic trees (PPCTs) exactly as in Pushkarev & Byzov (2014, Definition 2.1:
right decomposition → recursive transform → left decomposition), and checks:

1. **The implementation is correct.** The orbit-length distribution of `τ` on all
   PPCTs with `n` leaves reproduces Donaghey's orbit polynomials `M_n(x)`
   (Pushkarev–Byzov 2014, §7) for `n = 1, …, 10`. All ten match. (Note: the `x^18`
   term of Donaghey's `M_6` is a misprint; the `M_8` term is `x^48`, not `x^28`.)

2. **`τ` does not preserve the single-spine (caterpillar / comb) subfamily.**
   A PPCT is a caterpillar iff no internal vertex has two internal sons; these are
   exactly AEG's marked-history (single-spine) trees. There are `2^(n-2)`
   caterpillars with `n` leaves, but only `n-1` of them are mapped by `τ` to
   another caterpillar. The rest leave the comb subfamily immediately.

3. **Every long orbit is entirely branching.** At every `n` from 4 to 10, no orbit
   of length `> 6` contains a caterpillar. The "hyperbolic" long orbits
   (`48`, `72`, `144`, …) live entirely among branching trees.

- `COMPUTATIONALLY VERIFIED EXAMPLE` for the `τ`-implementation and the
  caterpillar non-invariance (`n ≤ 10`).
- This is a same-author finite computation; it is not an independent human
  review, and it does not prove the general-`n` statements.

## Files

## Reproduce

```bash
python3 verify_orbits.py evidence-v1.json
```

Exit code `0` iff all ten `M_n` checks match.
