# OQ-096 V2：同值异源与有限观察重开

日期：2026-11-02。地位：**COMPUTATIONALLY VERIFIED EXAMPLE**。
基线：`mountain/aeg-paper@1c7a1b2a20b8da2e34cd8921cb3314cf5df6523f`。
方向、候选与验收要求：苑明理。合同、实现、检查与报告：Codex（OpenAI）。
构造器与接收器分离，但由同一模型作者完成；独立进程重放不等于独立实现或人工审查。

本实验在 V1 的固定两事件计算和几何接口上另立语义合同，保持
`z=x+y; w=zt`、`t=4` 与槽位不变。V1 的六个直属文件（含把手校准）
逐字节保留，摘要列在 V2 合同中；未修改 V1 来接纳新输入。
V2 不生成新的几何构造，也不把来源差异解释成底层拓扑不同。

## 先固定的合同

[contract.json](contract.json) 在首次实验执行前固定，SHA-256：
`4eff959a029b79bd5b9ca2f62ceddb6faf9b708c2955db5bb0700333b3fa0e2c`。
接收器固定该摘要，合同再固定 V1 字节摘要；冻结证据另外绑定各个实现文件。

- **消费上下文：** `P:mul`，有序输入 `[z,t]`，输出 `w`；`t` 来自唯一的
  `common:t`，值为精确有理数 `4`。该上下文字段在所有实例中相同。
- **连接：** `Q:add` 的 `plus#1` 输出槽 `0` 到 `times#1` 输入槽 `0`；
  wire 为 `z`，类型为 `rational`。`Q:z:out` 与 `P:z:in` 是两个不同出现，
  绑定只关联它们，不合并身份。加法与乘法交换性均不授权交换槽位。
- **来源：** source 是不可变注册表键，对应类型、规范有理数值与 origin。
  A、B、C 的外部来源独立；`A-copy` 明确重用 A 的来源。
  这些是研究局部来源声明，不是对现实数据出处的认证。
- **occurrence：** 每个实例有新的 scope；六个端口出现和两个事件出现
  由 `scope/角色` 指定，跨实例不复用。source 复用不意味着 occurrence 复用。
- **历史／残余：** 保留两个按依赖排序的事件、输入值、输出值、来源、
  六个端口出现和连接。来源观察前必须重放并核验这些字段。
- **接收身份：** `--expected A` 等期望身份来自调用者的冻结清单，不从
  packet 的自报标签选取权限。一个合法的 B 包不能作为 A 被接收。

摘要仅作字节绑定，不是来源真实性证明。即使重算残余及整个 candidate 的
摘要，未经声明的来源替换仍应拒绝。若同时改写信任合同和检查器，已越出
本实验威胁模型；本检查器不是通用不可信数据接收服务。

## 两个观察者

令 `r` 是通过指定实例接收检查的完整记录。

- 数值观察 `N(r)=(z,4z)` 只读取接口数值及固定消费参数。实现
  `numeric_observation` 不访问历史、source 或 occurrence。
- 来源观察 `S(r)` 保留 `N(r)`、按槽位排列的输入来源记录、两个事件的
  source/op/wire/值轨迹与固定消费上下文。它按已验证角色消去 scope 与
  occurrence 的具体名字，避免仅凭运行编号得到伪区分。

在这五个合法记录上，分别以 `N(r)=N(r')` 和 `S(r)=S(r')` 定义等价。
程序比较完整规范记录，不以哈希不等代替来源观察的结构比较。
恢复生产者指的是读取并重放留存的 `add` 与有序输入，**不是从 `5` 反演历史**。
测试逐对检查来源等价蕴含数值等价，且增强观察保留原数值投影。

| 实例 | 输入来源 | `(x,y)` | `N=(z,w)` | 来源等价类 |
|---|---|---|---|---|
| A | A:x、A:y | (2,3) | (5,20) | {A,A-copy} |
| B | B:x、B:y | (1,4) | (5,20) | {B} |
| C | C:x、C:y | (2,3) | (5,20) | {C} |
| A-copy | 重用 A:x、A:y；新 occurrence | (2,3) | (5,20) | {A,A-copy} |
| different-value | A:x、B:y | (2,4) | (6,24) | {different-value} |

数值划分为 **2 类**：`{A,B,C,A-copy}` 与 `{different-value}`；来源划分为
**4 类**。共检查 30 个端口出现、10 个事件出现，身份全部新鲜。
A/B 的生产历史不同是**实例化输入与来源不同**；其 DAG 形状、运算符及
未实例化函数相同。C 排除“只是操作数值不同”；A-copy 排除“只是编号不同”；
第五个实例排除常量化的数值观察器。

数值包单独保存后仍能执行数值消费；把它直接提交给来源接收器因缺少完整
记录而拒绝。只有在残余另行保留、且正确绑定时，才可重开来源观察。
本实验实现的是声明观察范围内的闭合与观察增强，没有生成 Seal。

## 拒绝证据

20 项 packet 变异均要求准确的拒绝原因，19 项保持原来的 `(5,20)` 声明：

| 类别 | 变异 |
|---|---|
| 来源 | 同值来源 C:x 替换 A:x、改写 origin、未知 source、替换 gate source |
| 身份 | 合并接口 occurrence、连接别名化、整份合法 B 包冒充 A |
| 槽位 | 错误消费槽、错误生产槽、布尔值伪装槽号、交换加法槽位、交换输入记录 |
| 残余与历史 | 缺失残余、删除生产事件、无记录常量替换、伪造历史值、缺少输入来源、陈旧残余摘要 |
| 上下文与输出 | 改变消费参数、伪造数值输出 |

除专门的陈旧摘要案例，变异均重新计算 residual 摘要。新进程还逐一接收
这 20 个保存的坏包；另有 4 项证据文件变异（重算外层摘要的同值来源替换、
完整外来包替换、伪造等价类报告、调换实例顺序）及 JSON 重复键拒绝。
接受 A-copy 的正对照表明接收器允许合同声明的来源复用。
拒绝 C:x 代入 A 的理由是与期望请求不符，而不是 C:x 本身非法。
