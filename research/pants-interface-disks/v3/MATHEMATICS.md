## 1. 对象与定义域

三个块的有效部分函数为
\[
 Q:\mathbb Q^2\to\mathbb Q,\quad Q(x,y)=x+y,\qquad
 P:\mathbb Q\to\mathbb Q,\quad P(z)=4z,
\]
\[
 R:\mathbb Q\rightharpoonup\mathbb Q,\quad R(w)=1/w,\qquad
 \operatorname{dom}R=\mathbb Q\setminus\{0\}.
\]
端口层保留 P 的第二输入 t=4，以及 R 的有序输入 [u,w]、u=1；
所以三块仍各有两输入一输出、共九个端口。常参数的输入端口也是外部端口，
但不增加有效函数的自由变量。R 的 w 位于输入槽 1，u 位于输入槽 0。

约定 B∘A 先执行 A。部分函数相等必须同时满足定义域相等与其上的函数值相等。
本次的 domain:zero 是拒绝判断，不是被补入值域的无穷值或新数。

每个叶块具有有限记录
\[
 F=(E,O,B,L,G,\partial_{\rm in},\partial_{\rm out}).
\]
E 是带运算、gate-source、有序输入输出的事件表；O 是带角色、方向、槽位、
类型的端口表；B 是输出端口到输入端口的绑定表；L 是外部端口到来源记录的绑定；
G 是非零义务；两个边界是尚未被内部接线消费的有序端口。
事件与端口的 occurrence 都在组合前按调用者期望的 scope/role 分配，
三个叶块的 occurrence 集两两不交。source 可以重复引用，但相同 source
不允许把两个 occurrence 合并。来源表的值、类型、origin 均固定。

绑定表恰有
\[
 b_{QP}=(Q:z:out,\ P:z:in;\ 0,0),\qquad
 b_{PR}=(P:w:out,\ R:w:in;\ 0,1).
\]
端点 occurrence 始终不同。G 恰含 R 的分母输入非零义务。

组合运算只定义在这三个预先分配身份的叶块及其**连续子链**上。
它把互不相交的事件、端口和外部来源绑定取并，保留旧接线与旧义务，
加入相邻子链之间的指定接线，再由完整接线重算外部边界。
没有 quotient、隐式复制、隐式丢弃或按数值合并来源。开放子链 P∘Q 或 R∘P
允许保留未绑定输入；只有完整调用才执行具体数值重放。

produce.mjs 是这些受信叶块上的构造器，不是任意外来片段的通用接收器。
完整外来记录由 receive.mjs 检查。全局有向环检查先于固定链的接线表比较，
所以反馈拒绝并非只靠“与参考 JSON 不同”。

## 2. F1：固定三块的装饰组合相容性

**状态：proved with stated hypotheses。**

假设三个叶块使用同一调用者期望记录，预分配且互不相交的 occurrence，
不可变来源表与有序槽位，绑定仅为 b_QP、b_PR，并且保留全部生产事件、
端口、绑定、外部来源和非零义务。则
\[
 (R\circ P)\circ Q=R\circ(P\circ Q)
\]
在上述有限记录的规范表示上严格相等；两者均定义在
\[
 \{(x,y)\in\mathbb Q^2:x+y\ne0\},
\]
且在该定义域上给出相同的三个事件轨迹与输出 1/[4(x+y)]。

**证明。** 左括号化先引入 b_PR，后引入 b_QP；右括号化相反。由于旧接线
在第二步仍被保留，两边的最终接线表都是 {b_QP,b_PR}。
事件、端口、外部来源绑定分别为三个叶块对应集合的不交并；结合次序不改变它们。
来源记录没有重分配或合并；唯一非零义务来自 R，始终保留。
边界是完整端口与接线的确定函数，所以两边恰有外部输入
[Q:x:in,Q:y:in,P:t:in,R:u:in] 和输出 [R:v:out]。
规范排序只是表示，不删去角色或槽位信息。

完整依赖图只有执行次序 Q,P,R。由确定性依次得到 z=x+y、w=4z。
左边首先构造的开放 R∘P 的定义域条件是 4z≠0；代入 Q 得 4(x+y)≠0。
右边 P∘Q 在全部有理数对上有定义，再满足 R 的输入非零条件，亦得
4(x+y)≠0。因 4≠0，两边定义域均为 x+y≠0；各步输入与输出逐项相同。
定义域外，两边均在 R 的严格非零义务处拒绝。证毕。

这个证明针对所有有理数赋值成立，依据是上面的代数与有限记录并集论证，
不是把 36 个网格输入外推到全部有理数。有限枚举单独检验实现是否服从定义。
来源接收仍只授权合同中的具体请求；数学命题不额外授权任意外来来源。

相同调用内部使用同一套预分配身份，所以结论是严格相等，不需要 α 商。
跨 A/A-copy 比较时，先核对各自 scope/role 及来源授权，再消去 occurrence
名称；两者来源观察相等。未经核验先消去名字，会抹掉应当拒绝的身份冲突。
动态分配名字的一般相干重命名定理没有在这里证明。

## 3. F2：一个来源绑定的最小反例

**状态：proved in the specified finite model。**

请求 A 要求 Q 的槽 0 使用 A:x，值 2；槽 1 使用 A:y，值 3。
把唯一一个绑定 A:x 改为 C:x，后者也是值 2 的合法注册来源，保留其他字段。
两个数值计算都得到
\[
 (z,w,v)=(5,20,1/20).
\]
但请求 A 的来源判定要求 source(Q:x:in)=A:x，故替代包拒绝。
这是一个绑定被改变的反例；不改变任何绑定则无法构造这种来源替换。
“最小”只就改变的来源绑定数而言，并非关于一切计算语言的绝对最小性。

因此数值观察相等不足以推出来源接收合法，也不足以在该来源观察下将
两条生产记录等同。C:x 并非全局非法，而是不满足当前调用者的合同。

## 4. F3：数值结合但残余不结合的闭合代数

**状态：proved in the specified finite model。**

为精确化 SPEC 的 last-seam-only 候选，定义一个刻意不合格的组合政策。
对象为 (f,I,L)：f 是数值部分函数，I 是 Q<P<R 中的连续区间，
L 是接缝残余。对相邻区间 I_U 在前、I_D 在后的两个对象，规定
\[
 (f_D,I_D,L_D)\star(f_U,I_U,L_U)
 = (f_D\circ f_U,\ I_U\cup I_D,\ \{b_{\max I_U,\min I_D}\}).
\]
这里会**丢弃** L_D 和 L_U，只保存本次新接缝。该运算在这些区间类型上闭合。
数值部分函数仍按严格定义域组合；它不携带来源观察，也不提供旧残余的解码器。
实现用闭包计算数值映射，不把完整装饰图暗中保留为可恢复残余。
这是对冻结规范“保留数值计算”的具体化，不是改动 V1/V2 的实现。

令三个原子对象残余为空，则
\[
 (R\star P)\star Q:\ L=\{b_{QP}\},\qquad
 R\star(P\star Q):\ L=\{b_{PR}\}.
\]
数值部分相等，定义域也相等，但两个残余不同。角色与槽位固定，因此不能
以重命名把 Q→P 变成 P→R。对输入 (2,3) 两者输出都是 1/20。
三叶/两接缝是出现两种二元括号化的最小规模；少于三叶没有这种比较。

反例证明的是“数值结合不足以强迫装饰政策结合”，并不否定 F1。
它也不是在合法完整组合运算内部找到结合律失败：该政策明确违反保留旧残余
的假设。完整接收器拒绝两个不完整残余。

## 5. 哪些条件不可省略

“不可省略”始终相对于本次声明的来源观察与接收合同。

| 信息或条件 | 省略后的问题 | 可接受的弱化 |
|---|---|---|
| 调用者给定的期望来源 | 同值的合法 C:x 可以冒充 A:x | 只有明确改为更弱的来源观察才可忽略 |
| 不可变 source 与 occurrence 的区分 | 复用来源被误写成复用事件或端口 | 来源可共享，出现必须保持可区分 |
| 角色、类型、有序槽位 | 交换律被误用来授权错接；R 的输入更不可交换 | 需另立并证明新的槽位置换合同 |
| 先分配身份或相干的重命名运输 | 括号化可能改变命名或引入碰撞 | 本次仅证明先分配身份；一般 α 相干仍开放 |
| 全部旧接线、生产历史和非零义务可恢复 | F3 丢失旧接缝；丢弃非零义务改变严格域语义 | 经验证的无损压缩可以替代完整展开 |
| 全局无环及显式复制/丢弃规则 | 局部匹配仍可能形成反馈或隐含复用 | 必须进入另行定义的反馈/资源语义 |

这不声称每个 JSON 字段或人造编号都是任何数学表示中不可省略的。
必要的是观察者所需的信息及其运输相容性。本次完整展开是为了可检查。
摘要固定字节，不能证明现实出处；没有外部来源认证。
