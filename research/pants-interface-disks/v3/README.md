## 三块与两种括号化

| 块 | 有效类型与计算 | 固定参数及槽位 |
|---|---|---|
| Q | ℚ²→ℚ；z=x+y | 有序输入 [x,y] |
| P | ℚ→ℚ；w=4z | [z,t]；t 来自 V2 的 common:t=4 |
| R | ℚ∖{0}→ℚ；v=1/w | [u,w]；u 来自 common:u=1，w 是槽 1 |

比较 (R∘P)∘Q 与 R∘(P∘Q)，约定先执行右侧。
**括号化决定构造顺序，不改变执行依赖 Q→P→R。**
R∘P 是开放片段；保留符号化非零义务，再代入 Q。两边严格定义域均为 x+y≠0。

构造时先给每个叶块分配 occurrence；不交并保留全部事件、九端口、
两条绑定、四个外部来源及非零义务。source 允许合同明确的复用，
不允许据此复用或合并 occurrence。A-copy 因而有新身份但与 A 来源等价。

## 两个反例

1. **同值来源替换。** A:x 与 C:x 均为 2；只把 A 的第一个来源绑定改为 C:x，
   仍有 (z,w,v)=(5,20,1/20)，但与调用者期望 A 不符，拒绝。
   “最小”指只改变一个来源绑定。
2. **只留最后一次接缝的组合。** 数值部分函数正常组合，残余只保留此次新接缝，
   丢弃旧接缝。左括号化留下 {Q→P}，右括号化留下 {P→R}；
   数值与定义域相同，残余不同。三叶/两接缝是该二元括号化反例的最小规模。

第二项没有发现完整残余政策违反结合律；它精确否定“数值结合足以保证
任意来源/残余装饰也结合”。完整历史可以无损压缩；必要的是可恢复信息，
不是强制使用本实验的逐字 JSON 表示。
