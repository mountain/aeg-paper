## 固定几何与计算合同

取两个实体盒与连接管道：

\[
B_+=[0,3]^3,\quad
B_\times=[5,8]\times[0,3]^2,\quad
T=[3,5]\times[1,2]^2.
\]

全部按整数坐标分为单位立方体。沿

\[
D=\{4\}\times[1,2]^2,\qquad C=\partial D
\]

切开；左右各有 28 个立方体。四个外部端口为：

| 端口 | 指定闭圆盘（方形胞腔） | 语义 |
|---|---|---|
| x | {0}×[1,2]×[1,2] | 加法第一输入 |
| y | [1,2]×{0}×[1,2] | 加法第二输入 |
| t | [6,7]×{0}×[1,2] | 乘法第二输入 |
| w | {8}×[1,2]×[1,2] | 乘法输出 |

方形是拓扑圆盘，边缘是四条边组成的拓扑圆周。这里没有声称它们已经
携带光滑 AES 数据。四个外部圆盘的闭包彼此不交。

程序只有两个出现：plus#1 与 times#1：

\[
z=x+y,\qquad w=zt,\qquad (x,y,t)=(2,3,4).
\]

共享接口固定连接 plus#1 的输出槽 0 与 times#1 的输入槽 0。
Q:z:out 与 P:z:in 是被绑定的两个不同接口出现，不因值相等而合并。
这些是研究局部标识，不是新注册的 Adva 类型。

## 已执行的检查

[verify_v1.py](verify_v1.py) 构造显式有向胞腔链，再检查：

1. 体链的边界、边界的边界为零，以及共享圆盘在左右边界中符号相反；
2. 两侧去掉三个端口圆盘后各自是连通、可定向的三边界曲面；
3. 侧表面拼接保留四个外部边界，圆周 C 成为其内部接缝；
4. 每个立方体用兼容的 Freudenthal 剖分变成六个四面体；检查每个体顶点
   的 link 是球面或圆盘，并检查这些二维 link 的局部流形性与可定向性；
5. 各侧表面的所有顶点 link 为圆周或区间，边的面入射数为一或二；
6. 模二边界矩阵的精确秩，检查 C 能否在侧表面内填充；
7. 固定的类型、槽位、source、occurrence 与事件—补片对应；精确有理数
   求值与直接代换相等；
8. 十项负对照全部拒绝。

所有判定使用显式异常，不依赖会被 Python 优化模式删除的 assert。

## 结果

| 对象 | 顶点 V | 边 E | 方形 F | 立方体 | Euler 特征 | 边界圈数 |
|---|---:|---:|---:|---:|---:|---:|
| 整个体 H | 132 | 300 | 225 | 56 | 1 | 不适用 |
| 左侧 pants | 60 | 116 | 55 | 0 | −1 | 3 |
| 右侧 pants | 60 | 116 | 55 | 0 | −1 | 3 |
| 拼接侧表面 S | 116 | 228 | 110 | 0 | −2 | 4 |
| 内部圆盘 D | 4 | 4 | 1 | 0 | 1 | 1 |

整个体剖分为 **336 个四面体**。132 个顶点的 link 中，**16 个为球面，
116 个为圆盘**。左右半体也分别通过局部检查。球体结论同时使用
note 25 的显式盒—管构造证明，不从一个 Euler 数单独推断。

精确求值得到接口 **z=5**、输出 **w=20**，与直接计算 (2+3)·4 一致。

### 孔与盘的互补：同一个 C，两个不同填充判断

侧表面 S 的模二二链边界矩阵秩为 **110**；把 C 作为一列加入后，
秩升为 **111**，而 ∂C=0。因此

\[
[C]\ne0\in H_1(S;\mathbb F_2),
\qquad C=\partial D\text{ 在 }H\text{ 中}.
\]

S 的第一 Betti 数为 228−116+1−110=3。同一算法还确认 110 个单面
边界都属于边界矩阵的像，以及零链可以填充，作为正对照。

这个有限结果直接落实苑明理随后提出的视角：**表面规定孔口及绕孔的
拓扑阻碍，体提供圆盘及其填充位置。** 在完整侧表面上 C 是接缝而非
一个额外的开放边界；沿 C 切开后，它成为两侧的孔口。圆盘填在体中，
没有把四孔侧表面改成无孔表面。

### 负对照

拒绝了：翻转一条 C 的边、删除一个 pants 面、翻转一个 pants 面、
把外部端口当作内部圆盘、别名化两个端口、错接乘法槽位、合并接口
出现身份、删除生产事件。另直接对拓扑检查器提交仅顶点接触的两立方体
和带内部空腔的立方体盒，分别因局部 link 断开与边界断开而拒绝。
后两项不依靠固定坐标清单的相等检查来拒绝。
