% =========== Block A: to append to rem:capping-singular-branch-nonempty ===========
% (the remark after cor:capping-dichotomy in paper-1/sections/08-caps-and-interface-disks.tex)
%
% A CONICAL POINT IS NOT A DRILLED CAP
% The singular point produced above must not be confused with the drilled
% interface disks of the tunnel surgery: drilling a tunnel removes a tube from
% the body and replaces a filling disk by an annulus, which changes the side
% surface by chi(S) -> chi(S) - 2 and adds a handle
% (Proposition~\ref{prop:tunnel-boundary-surgery},
% Proposition~\ref{prop:pierced-cap-annulus}), whereas the conical point above is
% a failure of regularity of the analytic assignment $a$ on a disk that still
% fills its circle (Remark~\ref{rem:drilled-body-meridian}).  The two statements
% are complementary rather than competitive: the surgery records which fillings
% remain available topologically, and the present remark records that a disc
% filling with constant boundary value is available only at the price of one
% interior singularity.


% =========== Block B: to append to rem:drilled-body-meridian (PR #21) ===========
%
% A SURVIVING MERIDIAN DISK NEED NOT CARRY A REGULAR ASSIGNMENT
% Conversely, the meridian disks that survive the surgery are regular in the
% topological sense only.  The analytic assignment of
% Definition~\ref{def:surface-potential} cannot be continued across a circle
% whose boundary value is constant without admitting one interior singularity
% (Remark~\ref{rem:capping-scope-mu-essential},
% Remark~\ref{rem:capping-singular-branch-nonempty}), so the topological
% availability of a filling disk and the regularity of an analytic filling are
% separate questions.
