## 指定算子与精确反例

设 E={a,b,c}，带不可变事件标记。C 有覆盖边 a->b、b->c；F 有 b->a、b->c。事件序是自反传递
可达性。此处算子是**无权无向覆盖图** Laplacian，而非传递闭包或有向加权算子的 Laplacian。行列
用 a,b,c。两者都给出

    L = [[1,-1,0],[-1,2,-1],[0,-1,1]].

其特征多项式是 det(tI-L)=t(t-1)(t-3)；所有特征值恰为 0,1,3。验证器从整数主子式与行列式推导
多项式，不用浮点特征求解器。这些图有相同完整无向算子，故保留其特征向量也不能恢复被丢弃的
定向。

| 对象 | C | F |
|---|---|---|
| 严格序 | a<b, b<c, a<c | b<a, b<c |
| 下开 | empty, {a}, {a,b}, E | empty, {b}, {a,b}, {b,c}, E |
| 开计数 | 4 | 5 |
| 理想大小多项式 | 1+t+t^2+t^3 | 1+t+2t^2+t^3 |
| 有向覆盖邻接特征多项式 | t^3 | t^3 |

**PS-1 — 带所述假设证明。** 在这个两元素模型域上，指定无向 Laplacian 谱或有向邻接特征值重集
都不决定标记因果偏序。证明：上述相等谱有不同序（也不同的开数，故非同构偏序）。拓扑排序后
有向邻接矩阵严格三角，故幂零。最后论证适用于每个有限 DAG 的邻接矩阵，但不说明其他带标记与
乘积的有向算子或谱数据。

## 什么恢复什么

**PS-2 — 带所述假设证明。** 对有限偏序 P，其在标记事件载体上的完整下开族通过

    x <= y iff 含 y 的每个开都含 x

决定其标记序。证明：下闭包证明正向。若 x 不在 y 之下，主理想 down(y) 分离它们。此定向约定
显式；不静默导入相反特化序约定。

保留 meet/join/序但遗忘事件标记的抽象格 J(P) 决定 P 直到同构：其非空 join-不可约元恰是主
理想。主理想不能是两个真理想的并，因为其中一个必须含其生成元。非主理想至少有两个极大元，
是由它们生成的真理想之并。包含 down(x) subset down(y) 等价于 x<=y。这证明重构而不假设分类
定理。checker 独立用所有两两 join 识别不可约元，并在全部 19 个带标签三元素偏序上验证两个
重构。

| 候选数据 | 充分信息 | 损失/边界 |
|---|---|---|
| 无向 L 谱，甚至完整 L | 指定无向观测 | 定向在特征值提取前被擦除 |
| 有向邻接特征值 | 此 DAG 类中的幂零 | 所有特征值为零；无因果重构 |
| 计数或理想大小多项式 | 分离 C 与 F | 链与标记反链碰撞 |
| 带成员与事件标记的完整开 | 精确标记偏序 | 无线重数、源血统、运算或角色标签 |
| 带运算的抽象分配格 | 直到同构的偏序 | 字面事件标记丢失 |
| 带标签关联/zeta 矩阵 | 精确标记序 | 线性编码忠实；其特征值单独全为 1 |
| 开上完整带型端点标记线前沿 | 所述端口与源记录 | 需额外记录；非赢得的预层/粘合律 |
| 非线性 Laplacian 特征值 | 未测试构造 | 必须指定算子、域、归一化与重构目标 |

zeta 陈述由 zeta(x,y)=1 当且仅当 x<=y 推出：拓扑排序后它是对角 1 的上三角。故线性载体能保留
序而其仅特征值观测丢失它。理想大小多项式是组合格摘要，不是非线性谱。其系数计数在任何标记
偏序与其重标记上也一致；反标记链是显式负控制。不声称非线性必要性或现代谱理论的一般不可能
定理。基于 Alexandrov 的谱对象仍是结构提案：其乘法/关联、标记与装饰边界必须在忠实性断言
有意义前被指定。

## 来源、occurrence 与边界数据

对每个 U 脚本列出其生产者为外部输入或 U 中事件、其消费者在 U 外或为外部输出的线。每条线保留
生产者、消费者、occurrence ID、不可变源 ID、Q 类型、槽位与角色。外部输入/输出线被包含。这是
合成包上的 Research 0005 前沿约定，不是检查的原生授权。

例如 C 在 {a} 处的前沿是 a->b；F 在 {b} 处的前沿含 b->a 与 b->c。独立共享控制保持 F 与两个
occurrence 固定：两包有源 (s0,s0) 或 (s0,s1)，在 s0 与 s1 有相等 Q 值。源 ID 是声明的血统
元数据，不是事件序数据。无装饰拓扑及其所有格不变量一致；装饰前沿分离共享与独立起源。脚本
检查只有源字段改变。这些控制区别于早期默认图边界包，其源命名合成生产者位置。

对可比较不同事件间的有限无环线系统，完整前沿恢复每条线：事件事件线 x->y 穿越 down(x)；输入
线穿越空切割、输出线穿越全切割。端点/occurrence/源/类型/槽位/角色字段必须全部保留。这不恢复
事件运算体、内部隐藏状态或无线的注解。它不是任意程序语义忠实重构的证明，也不是传输/连贯
定理。

## 极小循环 anytime 模型

**定义（合成测试机）。** 一个控制位置在状态 x in N（初 0）上有自环 tick。每次 tick 设 x:=x+1
并发一个包：在第 k 次 tick 后 history=[0,...,k]、result=k+1、evidence={checked_steps:k+1}。
证据是生成记录，不是独立证明证书。每次 tick 有两个新 occurrence 标签与声明的等值零源槽位，
带共享血统 s0/s0 或独立 s0/s1。这些是元数据控制；它们不改变增量转移。这在控制位置极小；其
数据状态无穷。它不是有限状态循环机，也不是 Adva 的实现。

展开 n 次 tick 创建不同事件 e0,...,e(n-1)，一个有 n+1 下开的链。边从一 occurrence 到下一个；
事件不重复执行。控制转移 tick 重复执行。在视界 0,1,2,3,6 checker 验证前缀相容包与序。它拒绝
把自环控制图当作 DAG 事件图。

**PS-3 — 带所述假设证明。** 在可能在此前缀后停止的机器类中，无固定有限前缀决定此观测执行是否
无限继续。证明：对每个 n，把环与带计数器在 n 次 tick 后停止的机器比较。它们前 n 个包与展开
事件 DAG 一致；其启用未来 tick 不同。此前缀的无函数能区分其继续行为。脚本检查指定视界；量化
证明是对任意 n 的构造。这是关于从前缀恢复未知系统，而非执行已知转移规则。

| 区分 | 由装饰有限展开保留 | 继续所需额外信息 |
|---|---|---|
| 事件序 | 观测 occurrence 间序 | 未来启用与因果依赖 |
| 重复 | 带共同 tick 标签的不同 occurrence ID | 转移规则、循环与停止政策 |
| 源身份 | s0/s0 对 s0/s1 | 不可变血统传播政策 |
| 历史 | 完整发出前缀 | 观测与更新律 |
| 三输出角色 | 显式 history/result/evidence 键 | 原生角色类型、验证器与反馈路由 |

在同一控制位置，一次 tick 与三次 tick 有不同历史与结果。因此把 occurrence 商到 tick 标签对该
观测失败输出因式分解条件 PIV-S5。交换 history 与 evidence 键作为无序集合保留值但改变角色感知
包；源替换保留所有结果值但改变血统。两者都是已执行负控制。

固定 DAG 在其声明观测下忠实描述此有限前缀。它省略继续规则、末端对截断状态与可重复性，除非
它们被单独附着。所有展开的相容并是无限链 N；它恢复本次运行，不是所有反事实转移或备选输入。
已知更新规则加前沿状态可紧凑生成下一前缀，但历史观测输出不被约化为有限控制标签。一般循环
系统可能需要守卫、外部输入、分支与公平假设。此处无一个被静默推断。原生 Adva 三侧反馈与 AES
实现仍是 PIV-F2 开放义务。
