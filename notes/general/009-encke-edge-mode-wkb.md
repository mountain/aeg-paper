## 一、检验对象

OQ-104.3 的原表述：冷自引力 WKB 模式 `σ² = κ² − 2πGΣ|k|`，反射边界 `Σ₁(r_edge)=0`，Airy 转折点量子化 `∫_{r_edge}^{r_L}|k|dr = (n+3/4)π`，求离散边缘模式频率 `ω_n(m)` 与径向范围。

## 二、结果（负面）

对缝隙外缘 `r_edge = a_P + 162 km`、图样速度 `ω = mΩ_P`（Pan 的第 m 阶分量）：

| m | 转折点 r_L（Lindblad 共振） | 结论 |
| ---: | --- | --- |
| 100–500 | a_P + 178–889 km（**边缘之外**） | 有密度波，径向阶数 n ≈ 31–10342（**高 n**，非束缚边缘模） |
| **551** | a_P + 161.6 km（= 边缘） | 退化边界 |
| **≥ 551**（含实测 m≈2800） | a_P + 5–148 km（**缝隙内部**） | **无束缚模式** |

**关键**：转折点 `r_L = a_P((m+1)/m)^{2/3}`。`r_L > r_edge` 要求 `m < 551`；对 `m ≥ 551`，Lindblad 共振在**被清空的缝隙内部**，边缘处 `σ² > κ²` 是**倏逝区**，无传播波、无束缚模。

对实测 `m ≈ 2800`：`σ ≈ 5.1Ω`（远失谐），倏逝径向衰减长度

```
1/k_ev = (2πGΣ)/(σ²−κ²) ≈ 0.5 m
```

**约半米**——与观测边缘波（振幅 ~0.65 km、覆盖 360°、"wavelength varies smoothly"）完全矛盾。

## 三、结论

1. **冷 WKB 边缘模式对 `m ≥ 551` 不存在**（转折点在缝隙内），对 `m < 551` 退化为**高 n 密度波**（非束缚边缘模）。
2. 实测 `m ≈ 2800` 边缘波处于**远失谐倏逝区**（衰减长度 ~0.5 m），**不是**冷 WKB 边缘模式。
3. 因此 **OQ-104.3 的"冷自引力 WKB"表述被否定**。观测边缘波需要别的机制——压强（`c>0`，真正的 Papaloizou–Lin 束缚模）或 **Pan 的近场引力畸变（Hill 球/尾迹）**，二者都不是 OQ-104.3 原设的冷 WKB。

## 三·五、压强重检（Q≈6，2026-11-14 补）

把压强项加进色散 `σ² = κ² − 2πGΣ|k| + c²k²`（Toomre `Q = cκ/(πGΣ) ≈ 6.02`，`λ_crit = c²/(GΣ) ≈ 0.75 km`），重查边缘模式（见证 [009-encke-edge-mode-pressure.py](009-encke-edge-mode-pressure.py)）：

| m | σ/κ（边缘处） | 短波径向波长 |
| ---: | ---: | ---: |
| 551 | 1.01 | 210 m |
| 1000 | 1.83 | 125 m |
| **2800** | **5.11** | **47 m** |
| 10000 | 18.25 | 13.5 m |

**结论（仍是负面）**：边缘模式存在条件是**几何的**（转折点须在环内 `r_t > r_edge`，即 `ω < 0.99818(m+1)Ω_P`，对 `ω≈mΩ_P` 要求 `m < 548`），**与压强无关**。对 `m=2800`，边缘远失谐（`σ≈5.1κ`），压强只给出 ~47 m 的短波——不是观测的 ~0.65 km 径向振幅。**压强不能把 m≈2800 边缘波变成束缚边缘模**。
