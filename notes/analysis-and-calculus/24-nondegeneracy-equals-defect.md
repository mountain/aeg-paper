## 3. `[对应]` 待办 1：初式 ≠ 0 与 μλ ≠ 0 都是"非退化条件"（结构同构）

**Theorem（结构同构，`structural proposal`）**：初式 `≠0` 与 `μλ≠0` 是**两个结构各自的"非退化条件"**——结构在边界（初式=0 / μλ=0）处退化：

| | 初式 ≠ 0（吴）| μλ ≠ 0（AEG）|
|---|---|---|
| 结构 | 多项式除法 / 消元 | contact 水平分布 |
| 边界 | 初式 = 0（**不可逆**，除不动）| μλ = 0（**可积**，无曲率）|
| "穿透" | 伪除法（乘代替除）| 分配律（重标定代替朴素换序）|
| 载体 | 多项式环 | 仿射流 |

**精确的结构同构**：两者都是"结构在边界处退化的显式条件"，且"穿透"都是"把会失效的朴素操作换成永远成立的代数律，把退化推到边界"。`[对应]`（`structural proposal`）。

**但必须诚实标注的不对齐**：

1. **退化方式不同**：初式=0 是**不可逆**（乘法不可逆，除不动）；μλ=0 是**可积**（无曲率，加乘交换）。一个是"太奇异（除不动）"，一个是"太平凡（无缺陷）"。
2. **载体不同**：初式在**多项式环**（一个具体多项式），μλ 在**仿射流**（一个具体括号系数）。二者**不是同一数学对象**。

**结论**：待办 1 的"非退化条件 = 缺陷 μλ"是**结构层面对应**（都是"体-表面"里的"表面" = 结构的退化边界），**不是对象层面的同一**。这正是"同一个表面"的精确意义：**两者都是那个"结构的退化边界"，但各是各的退化。**

## 4. `[对应]` 待办 3：弱非退化 = 分配律交换（逐级穿透）

**Theorem（逐级穿透，`structural proposal`）**：张景中"弱非退化条件"改进吴法，与 AEG"分配律交换"改进"朴素交换"，是**同一"逐级穿透"**：

| | 强（吴 / 朴素）| 弱（张 / 分配律）|
|---|---|---|
| Adva | 强非退化（初式≠0，只在可除处成立）| **弱非退化**（更大 locus）|
| AEG | 朴素换序（有缺陷 μλ）| **分配律重标定**（无缺陷）|
| 机制 | 会失效的朴素操作 | 永远成立的代数律 |
| 边界 | 边界大（初式=0 / 换序有缺陷）| 边界**推小**（弱非退化 / 无缺陷）|

**证明（对应）**：张的"弱非退化"把吴法"只在初式≠0 成立"放宽到更大 locus——即**把"会失效的操作"再替换一层**；AEG 的"分配律交换"把"朴素换序（有缺陷）"替换为"重标定（无缺陷）"——同样是**再替换一层**。二者是同一"逐级穿透：把边界逐级推小，直到只剩不可再推的残余"。`[对应]`（`structural proposal`）。

**关键对齐**：吴→张的"强非退化→弱非退化"改进，对应 AEG 的"朴素交换→分配律交换"——**都是"穿透一层、边界推小一层"**。残余（初式=0 处 / 缺陷 μλ）就是那个"不可再推的表面"。
