## 1. `[Adva]` 三家方法的机制（原文可追溯）

### 1.1 吴消元法（特征列 / 伪除法）— `0181`/`0182`

把命题写成多项式：假设 `H`、结论 `C`。用**伪除法**把 `H` 三角化成**特征链**（升列），再把 `C` 依次做**伪余式归约**：

> 余式为 0 ⟹ `C` 在 `H` 的零点集上恒为 0（在链的**初式不消失**的区域内）。

**关键操作**：伪除法 `prem(f,g) = lc(g)^m·f − q·g`——**乘代替除**（`lc(g)` 在奇点处为零，故不能除；乘永远能做）。`0181` §1、`0182` §1。

**非退化条件**：初式（首系数）不消失处成立；`0182` 记"首系数（120 项、6 次）就是非退化条件，不是可以省略的脚注"。

**突破到一般圆锥**：`0182` 把"六点共一条圆锥曲线"（六次行列式，720 项）作为单个高次假设，一次伪余式归约即可——"只要首系数非零，一次归约就够了，这正是吴方法最经典的用法"。

### 1.2 杨路差分代换 — `0185`

变量非负时，把第 `j` 小的变量换成前 `j+1` 个差分变量之和。在有序锥上，这个代换恰好换到非负差分变量，所以**代换后系数全非负 ⟹ 该锥上非负**。对全部 `n!` 个次序都通过 ⟹ 整个非负象限上非负。

**关键操作**：差分代换 + **展开成单项式、查系数符号**（分配律把不等式压成"单项式系数非负"的可判定形式）。`0185` §3。

### 1.3 张景中消点法（面积法）— `0183` + `zhang_area_method`

按构造的**逆序**逐个消去构造点，每消一点用一条**命名引理**（`S` 双倍面积、`R` 比、`Py` 勾股差），直到只剩自由点，再用精确域算术判定。

**关键操作**：逆序消点 = "三角化"（descend）；每条引理是面积量上的恒等式。`zhang_area_method/calibration.py` §"WHAT THIS IS"。

**弱非退化条件**：`0183` §2.2 第(3)条记张景中提出"**弱非退化条件**算法，**改进了吴法**"——把吴法的"强非退化（初式≠0）"往奇点上再穿透一层。

## 2. `[AEG]` 半直积 / 分配律 / 缺陷（已建立）

### 2.1 半直积分配律 — `paper-0` §9 + 前序笔记

加（平移 `T_s`）与乘（伸缩 `D_k`）之间的精确关系是**半直积**：

\[
D_k\circ T_s = T_{ks}\circ D_k,
\]

即"先加 `s` 再乘 `k`" = "先乘 `k` 再加 `ks`"——**分配律 = 给平移重标定 `s ↦ ks`**。`[AEG]`（`paper-0` §9 的仿射流；半直积结构 `Aff = ℝ⋊ℝ^×` 为 `CLASSICAL`）。

### 2.2 缺陷 = 朴素交换的失败 — `paper-0` §9、`18`/`20`

朴素交换 `T_s∘D_k` 与分配律交换 `D_k∘T_s` 之差：

\[
s(k-1) = \mu h(e^{\lambda k}-1) = T_{\mathrm{open}},
\]

密度 `μλ`（contact 曲率 `[D_u,D_v]=μλ∂a`）。`[AEG]`（`paper-0` `eq:exact-open-contact-defect`、`thm:contact-curvature`）。

### 2.3 交换性（同型内）+ 分配律（异型间）治理 DAG — `15`/`17`/`20`

- 加加、乘乘**交换**（`[T_s,T_{s'}]=0`、`[D_k,D_{k'}]=0`）——同型内自由换序。
- 加乘之间靠**分配律**（半直积）治理——异型间是精确的（无缺陷），只有朴素交换有缺陷。
- DAG（下集格 `O(P)`）由这三条律精确治理，缺陷 `μλ` 是半直积非交换密度。`[AEG]`（`15` §3、`17` §4、`20`）。

### 2.4 体-表面 + 级数 + 非退化 — `19`/`21`

体（DAG、紧致元）平；曲率 `μλ` 住表面（理想边界）作为 holonomy；级数（Magnus）的 arity-k 项 ↔ `O(P)` 的 k 元反链。`[AEG]`（`19`、`21`）。

## 3. `[对应]` 逐条对表（本笔记的合成）

| 维度 | `[Adva]` 吴/杨/张 | `[AEG]` 半直积/缺陷 | 对应关系 |
|---|---|---|---|
| **会失效的朴素操作** | 除（奇点处 `lc=0`）；逐点判定（退化配置）；构造点（奇点）| 朴素换序 `T_s∘D_k`（异型间不交换）| 三者都是"在奇点/缺陷处失效的朴素操作" |
| **永远成立的代数律** | 乘（伪除法）；单项式展开（差分代换）；引理消元（消点法）| 重标定 `T_{ks}∘D_k`（分配律）| 都是"交换性 + 分配律精确成立的代数律" |
| **残余（显式边界）** | 初式（非退化条件）；弱非退化条件 | 缺陷 `μλ`（曲率）| **非退化条件 = 缺陷 μλ** |
| **低维（奇异）→ 高维（精确）** | 簇 → 理想/坐标环；单配置 → `n!` 次序；构造点 → 自由点 | 线程 → DAG/下集格 `O(P)` | 都是"从会失效的低维层升到精确的高维层" |

## 5. 待办与核验结果

**待办 1 已完成（2026-10-31）。核验结论：**

`[Adva]` 原文 0181–0185 里**没有**"穿透奇点""更高维度""breakthrough"这三个确切措辞——它们是**苑明理的 framing（转述）**，不是 Adva 原文的现成用语。Adva 原文的实际词汇是两对：

| 苑明理 framing | Adva 原文词汇（可追溯）|
|---|---|
| 穿透奇点 | **非退化条件 / 退化轨迹**（`0181`/`0182`"初式不消失的区域"、`0183`"弱非退化条件算法改进吴法"）|
| 更高维度 / breakthrough | **消元 / 三角化 / 消点**（`0181`"三角化成特征链（升列）"、`0183`/`0184`"逆构造序消点"）|

**Adva 原文里最硬的两条（`[Adva]`，0183 §5.5(5)）**，精确支撑了 `[对应]` 的"非退化条件 = 缺陷 μλ"：

- "**图卡的分母就是吴法的初始（可核对）**"；
- "**参数化假设流形所丢掉的退化轨迹，与吴法的非退化条件是同一个对象**"。

即：Adva 原文已确认"**退化轨迹（= 非退化条件）是三条路线（吴法 / 例证法 / 消点法）都要面对的同一个对象**"；而 AEG 里"缺陷 `μλ`"正是"朴素操作失效处的显式边界"——**两者是同一个"表面"**。`[对应]`（`structural proposal`，经此核验后"非退化条件 = 缺陷 μλ"的对应有了 Adva 原文的正面支撑）。

**剩余待办（未闭合）：**

1. **[\对应 待验 → 已推进]** 吴法**初式** ↔ AEG **曲率 μλ** 的精确对齐。**已推进（2026-10-31，`24-nondegeneracy-equals-defect.md` §3）**：初式 `≠0` 与 `μλ≠0` 都是"非退化条件"（结构同构），但**退化方式不同**（初式=0 是"不可逆"，μλ=0 是"可积"）、**载体不同**（多项式环 vs 仿射流）——"非退化条件 = 缺陷 μλ"是结构对应，非对象同一。
2. **[\AEG 待补 → 已推进]** 杨路差分代换 ↔ Magnus 展开。**已推进（`23`）**：差分代换 = 缺陷 μλ=0 时的 Magnus（阿贝尔化）。
3. **[\对应 待立 → 已推进]** 张"弱非退化条件" ↔ AEG"逐级穿透"。**已推进（`24-nondegeneracy-equals-defect.md` §4）**：张"弱非退化"改进吴法 = AEG"分配律交换"改进"朴素交换"，同一"逐级穿透"（边界逐级推小）。

**残余（`24` §6，`open`）**：(a) "不可逆 vs 可积"两种退化是否对应 `09`–`13` 的乘性/加性两侧；(b) "逐级穿透"是否有多级（弱非退化之后更弱 ↔ arity-3+ 括号）。
