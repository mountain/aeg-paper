# 098.3 order-4 精确对接：carousel 的 `J` 对 Hecke `C₄` 的**平方** `R²`，不是 `R` 本身

## 从"都称 order-4"到精确矩阵对比

### Research Note v0.1 · 2026-11-01

**结论（精确，已计算）**：carousel 的 `J`（`J²=-I`）与 Hecke `C₄` 的生成元 `R`（`R⁴=-I`）**并不直接对应**——它们的特征多项式不同（`λ²+1` vs `λ²-√2λ+1`）。**精确的对接是**：

$$
\boxed{J_{\text{carousel}}\big|_{\text{plane}}\ \sim\ R_{\text{Hecke}}^{\,2}}
$$

即 **carousel 的复结构 `J` 与 Hecke `C₄` 生成元的平方 `R²` 共轭**（二者都是 `λ²+1`、本征值 `±i`、`(·)²=-I`）；而 **`R` 本身是 `J` 的一个"平方根"**（`R² ≈ J`）。换言之：**carousel 的"order-4 旋转"是 Hecke `C₄` 的"平方"，不是 Hecke `C₄` 的生成元本身。**

## 1. 两侧的精确形态

### AEG 侧（`paper-5/sections/04-six-state-carrier.tex`）

- `E=⟨T,S,R⟩`，满足 `T²=S²=R²=1`、`ε_iε_j+ε_jε_i=0`（**Clifford `Cl(3)`**）。
- `W=Λ¹E⊕Λ²E=⟨T,S,R⟩⊕⟨SR,RT,TS⟩`，`dim_ℝ W=6`；三平面 `W_T=⟨T,SR⟩`、`W_S=⟨S,RT⟩`、`W_R=⟨R,TS⟩`。
- `Ω=TSR`，中心，`Ω²=-1`；`J=Ω·`。
- **计算**：`J²=-I`、`J⁴=I`、`χ_J=(λ²+1)³`；**每个平面上的限制都是 `[[0,-1],[1,0]]`**。

### Hecke 侧（`eq:q4-sign-kernel-presentation`）

- `Γ_4=⟨J_h,R∣J_h²=R⁴=1⟩=C₂*C₄`；`T=J_hR`。
- 矩阵：`J_h=[[0,-1],[1,0]]`、`T=[[1,√2],[0,1]]`，故 `R=J_hT=[[0,-1],[1,√2]]`。
- **计算**：`R⁴=-I`；`χ_R=λ²-√2λ+1`；本征值 `e^{±iπ/4}`；在 `SL₂` 中阶 8、在 `PGL₂` 中阶 4。
- 而 `R²=[[-1,-√2],[√2,1]]`，`(R²)²=-I`；`χ_{R²}=λ²+1`；本征值 `±i`；在 `SL₂` 中阶 4、在 `PGL₂` 中阶 2。

## 2. 精确对接

| | carousel `J`（单平面）| Hecke `R` | Hecke `R²` |
|---|---|---|---|
| 矩阵（典范形）| `[[0,-1],[1,0]]` | `[[0,-1],[1,√2]]` | `[[-1,-√2],[√2,1]]` |
| 特征多项式 | `λ²+1` | `λ²-√2λ+1` | **`λ²+1`** |
| 本征值 | `±i` | `e^{±iπ/4}` | **`±i`** |
| `(·)²` | `-I` | `-I`（`R⁴=-I`）| `-I` |
| 线性群阶 | 4（`GL`）| 8（`SL₂`）| 4（`SL₂`）|
| 射影群阶 | 2 | 4 | 2 |

**逐字对比**：`J` 与 `R²` **完全一致**（`λ²+1`、`±i`、`(·)²=-I`、线性 4/射影 2）。所以：

$$
J\ \sim\ R^2 \quad(\text{同为复结构，共轭}),\qquad
R^2 = \text{一个复结构},\quad R = \text{该复结构的平方根}.
$$

**计算验证**（`research/iota-carousel/verify_order4.py`）：`J` 的 `χ=λ²+1`、`R²` 的 `χ=λ²+1`，故**共轭**（同为 `2×2` 实矩阵、trace 0、det 1）。

---

## 3. 为什么 `J ↔ R`（直接）不成立

`R` 的 `χ_R=λ²-√2λ+1`（本征值 `e^{±iπ/4}`），而 `J` 的 `χ_J=λ²+1`（本征值 `±i`）。**不同 → 不共轭**。所以"carousel `J` = Hecke `C₄`" 的字面读法是**错误**的；正确是 **`J` = `R²`**（`C₄` 生成元的平方）。

**直觉**：`C₄` 的生成元是"四分之一转"（`R⁴=-I` ⇒ `R` 是 `-I` 的四次根，即 `i` 的平方根）；而 carousel 的 `J` 是"复单位"（`J²=-I`）。二者差**一次开方**：`R` 是 `J` 的平方根。

## 4. 与 note 40/42 的衔接

- note 40/42 说"carousel 的 order-4 旋转 ↔ Hecke 的 `C₄`"——**本笔记把这个"结构性说法"精确化为 `J ↔ R²`**。
- 这也解释了 note 42 的"结构对应成立、增长律不成立"：**对应是"复结构层"（`J ↔ R²`），不是"生成元层"（`J ↔ R`）**；增长律（替换 Perron 值 vs 测地熵）则完全是另一层。
- **符号字符的平行**（次要）：Hecke 的 `χ(J_h)=χ(R)=-1`（生成元"奇"）∥ carousel 的手性符号律 `P_π Ω P_π^{-1}=sgn(π)Ω`（奇置换反号）。两者都是"符号字符"，但一个在 `Γ_4` 上、一个在 `S_3` 上——**尚未建立同一性**。

## 5. 结论与地位

| 命题 | 地位 |
|---|---|
| §1 AEG `J²=-I`、`J⁴=I`、三平面 `[[0,-1],[1,0]]` | `CLASSICAL`（Paper 5 `prop:one-complex-unit`）+ 计算 |
| §1 Hecke `R⁴=-I`、`χ_R=λ²-√2λ+1`、`(R²)²=-I`、`χ_{R²}=λ²+1` | `CLASSICAL` + 计算 |
| §2 `J`（单平面）与 `R²` 共轭（同 `λ²+1`）| **`[对应]` 精确（计算 + 特征多项式）** |
| §2 `R` 是 `J` 的平方根（`R²≈J`）| **`[对应]` 精确** |
| §3 `J ↔ R` 不成立（`χ` 不同）| **`PROVED`（计算）** |

**残余（`open`）**：
1. **同构的"自然性"**：`J` 与 `R²` 只是在裸线性空间上共轭；是否存在**自然**（不依赖基的选择）的等同？需要共同空间（六态 `W` 与 `H²` 的切空间）。
2. **六态 vs 三平面**：carousel 的 `J` 是 `W` 上"3 份"标准复结构（`χ=(λ²+1)³`）；Hecke 的 `R²` 是 `H²` 切空间上"1 份"。**三 vs 一**——是"三平面 ↔ 三个特殊点（尖点/2阶/4阶）"吗？
3. **符号字符的同一性**：`χ_{Γ_4}` 与 carousel `sgn` 是否同一个？（§4）
4. **`R` 的"四次根"**在 carousel 侧对应什么？（若 `J=R²`，则 `R` 对应"`J` 的平方根"——carousel 有无"`J` 的平方根"？）
