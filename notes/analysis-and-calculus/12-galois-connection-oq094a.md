# OQ-094a §5.2：Galois 连接

## 把"平行构造"升级为"交换图"的最小可证一步

### Research Note v0.1

**2026-10-31**（v0.1：闭合 `11-oq094a-proof-skeleton.md` §5.2 的 Galois 连接；证明"补上 ¬"在两条 Galois 映射下都交换，并指出自同胚层只能到 `Stab([0,∞])`、要到 `PGL₂` 必须用自映射层）

---

## 0. 目标

`11` §5.2 问：能否用 Galois 连接把 `11` §4 的"平行构造"（拓扑 join `σ∨¬_*σ=λ` 与子群 join `⟨Aff^+,¬⟩=PGL₂`）升级为**交换图**。本笔记给出最小可证的一步：**两条自然 Galois 映射都满足"补上 ¬ 交换"**，并精确指出二者分别落到哪一层。

**结论预告**：

- **自同胚层**（`τ ↦ Homeo(L,τ) ∩ PGL₂`）：`Homeo(L,σ)∩PGL₂ = {D_k}`，补 ¬ 得 `Stab([0,∞]) = ⟨D_k,¬⟩ = Homeo(L,λ)∩PGL₂`。这条**只到 `Stab([0,∞])`，到不了 `PGL₂`**——因为平移 `T_s` 不是自同胚（不 onto）。
- **自映射层**（`Aff^+ = C(L,σ) ∩ B_∞`）：补 ¬ 得 `PGL₂ = ⟨Aff^+,¬⟩`。这条**到得了 `PGL₂`**——因为 `Aff^+` 含不可逆平移 `T_s`。

即：**"Lawson ⟷ PGL₂" 必须读在自映射（半群）层，不能读在自同胚（群）层**；自同胚层只给 "Lawson ⟷ `Stab([0,∞])`"。

## 1. 记号（沿用 `11`）

`L=[0,∞]`，Scott `σ`、下 `ω`、Lawson `λ`。`T_s(a)=a+s (s≥0)`、`D_k(a)=ka (k>0)`、`¬(a)=1/a`。`Aff^+ = {ka+s : k>0, s≥0}`，`B_∞ = Stab_{PGL₂}(∞) = {ka+s : k∈ℝ^×, s∈ℝ}`。

三条 Galois 数据：

- `C(L,τ)` = `(L,τ)` 的连续自映射（**自映射幺半群**；含不可逆元）。
- `Homeo(L,τ)` = `(L,τ)` 的自同胚群。
- 二者与 `PGL₂(ℝ)`（或 `B_∞`）取交得"射影部分"。

---

## 2. 关键事实（全部可证）

### 2.1 引理 A：Scott 连续自映射的仿射部分恰为 `Aff^+`（`CLASSICAL` + 平凡核对）

**命题**：`C(L,σ) ∩ B_∞ = Aff^+ = {a ↦ ka+s : k>0, s≥0}`。

**证明**：`f ∈ C(L,σ)` ⟺ `f` 单调且保定向并（Scott 连续）。仿射元 `a ↦ ka+s` 保定向并恒成立；单调 ⟺ `k>0`；且为 `[0,∞]` 自映射需 `s≥0`（`a=0 ↦ s`）。故 `C(L,σ) ∩ B_∞ = {ka+s : k>0, s≥0} = Aff^+`。∎

### 2.2 引理 B：Scott 自同胚的射影部分恰为 `{D_k}`（`CLASSICAL` + 平凡核对）

**命题**：`Homeo(L,σ) ∩ PGL₂(ℝ) = {D_k : k>0}`。

**证明**：`h ∈ Homeo(L,σ)` ⟺ `h, h^{-1}` 均 Scott 连续 ⟺ `h` 是递增双射（序自同构）。递增 Möbius 双射 `a ↦ (αa+β)/(γa+δ)` 必须固定端点 `{0,∞}`（它们是链的底/顶）：`h(0)=0 ⟹ β/δ=0 ⟹ β=0`，`h(∞)=∞ ⟹ α/γ=∞ ⟹ γ=0`，故 `h(a)=(α/δ)a=ka`；递增 ⟺ `k>0`。故交为 `{D_k}`。∎

### 2.3 引理 C：Lawson 自同胚的射影部分恰为 `Stab([0,∞]) = ⟨D_k,¬⟩`（平凡核对 + 机器核对）

**命题**：`Homeo(L,λ) ∩ PGL₂(ℝ) = Stab_{PGL₂(ℝ)}([0,∞]) = {D_k, D_k¬ : k>0} = ⟨D_k(k>0), ¬⟩`。

**证明**：`λ` = 欧氏（`11` 引理 C），故 `Homeo(L,λ)` = `[0,∞]` 的欧氏自同胚；其 Möbius 部分 = 把 `[0,∞]` 集态地映到自身的射影映射 = `Stab([0,∞])`。逐案（`h(0), h(∞) ∈ {0,∞}`，且 `ad-bc≠0`）：

- `h(0)=0, h(∞)=∞` ⟹ `β=0, γ=0` ⟹ `h(a)=(α/δ)a = D_k`（`k=α/δ>0`，因保持 `[0,∞]`）；
- `h(0)=∞, h(∞)=0` ⟹ `δ=0, α=0` ⟹ `h(a)=(β/γ)/a = D_k¬`（`k=β/γ>0`）；
- 其余两案（`β=0,α=0` 或 `δ=0,γ=0`）给出 `ad-bc=0`，排除。

故 `Stab([0,∞]) = {D_k} ∪ {D_k¬} = ⟨D_k, ¬⟩`（`¬D_k = D_k¬`、`D_kD_{k'} = D_{kk'}`）。`computationally verified example`：对 `{D_k, ¬}` 的词做枚举，射影类恰为 `[[1,0],[0,c]]`（对角）与 `[[0,1],[c,0]]`（反角）两类，无平移 `[[1,1],[0,1]]`。∎

### 2.4 引理 D：`λ` 是含 `σ` 且使 `¬` 成为自同胚的**最粗**拓扑（平凡核对）

**命题**：`λ = σ ∨ ¬_*σ` 是满足 `τ ⊇ σ` 且 `¬ ∈ Homeo(L,τ)` 的最粗 `τ`。

**证明**：`¬` 连续 ⟹ `¬^{-1}((r,∞]) = [0,1/r)` 开（因 `(r,∞] ∈ σ ⊆ τ`），故 `τ ⊇ {[0,1/r)}` = 下拓扑子基，故 `τ ⊇ σ ∨ ω = λ`。反向：`¬` 确是 `λ`-自同胚（`11` 引理 B：`¬_*σ = ω`，且 `¬` 反序双射把欧氏拓扑映回自身）。∎

### 2.5 引理 E：`⟨Aff^+, ¬⟩ = PGL₂`（`11` 引理 F + Bruhat，`proved`）

**命题**：`⟨Aff^+, ¬⟩ = ⟨B_∞, ¬⟩ = PGL₂(ℝ)`。**证明**：`D_{-1} = T_1¬T_{-1}¬T_1¬`（`11` 引理 F，机器核对），故 `B_∞ ⊆ ⟨Aff^+,¬⟩`，再由 Bruhat。∎

## 3. 主定理：两条 Galois 映射都满足"补上 ¬ 交换"

**Theorem (OQ-094a §5.2 的最小可证步).**

**(自同胚层)** 令 `Φ_homeo(τ) := Homeo(L,τ) ∩ PGL₂(ℝ)`。则

\[
\Phi_{homeo}(\sigma) = \{D_k : k>0\},
\qquad
\Phi_{homeo}(\lambda) = \operatorname{Stab}([0,∞]) = \big\langle \Phi_{homeo}(\sigma), \neg \big\rangle .
\]

即 `Φ_homeo` 使"补上 ¬"交换：`Φ_homeo(σ ∨ ¬_*σ) = ⟨Φ_homeo(σ), ¬⟩`。

**(自映射层)** 令 `Aff^+ := C(L,σ) ∩ B_∞`。则

\[
\operatorname{Aff}^+ = \{ka+s : k>0, s≥0\},
\qquad
\langle \operatorname{Aff}^+, \neg \rangle = \operatorname{PGL}_2(ℝ).
\]

即自映射层的"补上 ¬"给出全 `PGL₂`。

**二者统合**：拓扑侧"补上 ¬"= `λ = σ ∨ ¬_*σ`（引理 D 的最粗刻画）；群侧"补上 ¬"= `PGL₂ = ⟨Aff^+, ¬⟩`（引理 E 的最小生成）。**两侧都是"对同一生成集加 ¬ 再取闭包"（拓扑格 join / 子群格 join）**，且第二操作数同为 `¬ = C_{/,1}^{(2)}`。这是把 `11` §4 的"平行构造"升级为**逐点交换**：`Φ(σ) ↦ ⟨Φ(σ), ¬⟩ = Φ(λ)`（在自映射层取 `Φ = C(-,·)∩B_∞` 于 `σ` 处）。

**证明**：引理 B、C 给自同胚层；引理 A、E 给自映射层；引理 D 给最粗刻画。∎

## 4. 关键发现：为什么必须用自映射层

自同胚层与自映射层给出**两个不同的"双侧"**：

| 层 | Scott 侧 | 补 ¬ 后 | 到达 |
|---|---|---|---|
| 自同胚 `Homeo ∩ PGL₂` | `{D_k : k>0}`（纯伸缩）| `Stab([0,∞]) = ⟨D_k,¬⟩` | **真子群** `⊊ PGL₂` |
| 自映射 `C ∩ B_∞` | `Aff^+ = {ka+s}`（含平移）| `PGL₂ = ⟨Aff^+,¬⟩` | **全体** `PGL₂` |

差别全在**平移 `T_s`**：

- `T_s`（`s>0`）是 Scott 连续**自映射**但**不是自同胚**（像 `[s,∞] ⊊ [0,∞]`，不 onto）。所以它属于 `Aff^+`（自映射层）却不属于 `Homeo(L,σ)`（自同胚层）。
- `Homeo(L,σ) ∩ PGL₂ = {D_k}` 丢掉了 `T_s`，故补 ¬ 只能到 `Stab([0,∞])`。
- `Aff^+ = C(L,σ)∩B_∞` 保留了 `T_s`，故补 ¬（经 `D_{-1}=T_1¬T_{-1}¬T_1¬`）到全 `PGL₂`。

这正是 `11` §5.1 所记"半群 vs 群"之区别的**拓扑化身**：`T_s` 的不可逆性（在 `[0,∞]` 上）是 Scott 单侧性的本质，也是"Lawson ⟷ PGL₂"必须用自映射层才能成立的原因。

## 5. 残余（仍 open 的完整函子化）

本节证明了**在对象 `σ, λ` 上**两条 Galois 映射的交换性（最小可证步）。仍未闭合的是把 `Φ` 定义为**整个 `Top(L)` 上的函子**并证明其 join 保持（`11` §5.3）：

1. **`Φ_homeo` 非单射**：很多拓扑有相同的射影自同胚群（`τ ↦ Homeo(L,τ)∩PGL₂` 会坍缩）。故 `Φ_homeo` 不能成为等价；它只在 `σ, λ` 这两个对象上给出交换性。
2. **`Φ_endo = C(-,·)∩B_∞` 在 `σ` 与 `λ` 上取同值**（`C(L,σ)∩B_∞ = C(L,λ)∩B_∞ = Aff^+`，因仿射自映射不区分 `σ`/`λ`）。故它单独不能探测双侧性；双侧性由"补 ¬ 后取群闭包"（`⟨Aff^+,¬⟩ = PGL₂`）承载。
3. **真正的 Galois 等价**需要一对互逆映射：`τ ↦`（连续自映射半群的射影部分，连同其群闭包）与 `G ↦`（由 `G` 生成的"Scott-连续可观测量"拓扑），并在中间层 `σ ⊆ τ ⊆ λ` 上建立 `Top(S) ⊣ C(-,·)` 的双射性。这需要固定一个"生成集 `S`"的典范选择（本骨架取 `S = {T_s : s≥0}`，`σ = Top(S)`），且验证 `Top(S ∪ {¬}) = λ` 与 `⟨S∪{D_k}∪{¬}⟩ = PGL₂` 的严格对应。此步为 `open problem`，不阻塞 §3 的结论。
