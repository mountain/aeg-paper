## 0 扩展是什么

AEG 的接口记录（Def 10.11）是五元组
$$\mathcal I_e=(D_e,\,C_e;\;\sigma_e,\;r_e,\;\beta_e).$$
V4 的结论是"缺纤维上的测度"，V5 的结论是"那个测度 = 表示空间 + 转动"。V6 把它落成三个新字段：

$$\boxed{\mathcal I_e^{+}=(D_e,\,C_e;\;\sigma_e,\,r_e,\,\beta_e;\;
V_e,\;\langle\cdot,\cdot\rangle_e,\;U_e)}$$

| 字段 | 内容 | 备注 |
|---|---|---|
| $V_e$ | 缝上的有限维表示空间，$\dim V_e=2j+1$ | 标签 $j$ 是**离散**的 |
| $\langle\cdot,\cdot\rangle_e$ | 非退化配对，**允许不定号** | 光子给号差 $(2,1)$ |
| $U_e\in U(V_e)$ | 沿缝的平行移动（Wigner $d^j(\theta)$） | 连续数据只在这里 |

## X1 退化检验：一维 + 恒等 ⇒ 精确退回 AEG 的标量读数

| 情形 | 权重 | 判定 |
|---|---|---|
| $\dim V_e=1$、$U_e=\mathbb 1$ | $T$ | **退回值层读数** ✓ |
| $\dim V_e=1$、$U_e=e^{i\phi}$ | $T\,e^{i\phi}$，模 $=1$ | 一个相位乘一个数 |
| $j=1$ | $T$、离散标签 $j$、$3\times3$ 转动 | 读数变成三元组 |

第二行是个意外的连接：**"一维态空间 + 相位"正好是 11 天前那份电动力学稿 Remark 2.9 的说法**
——"同一终点、不同 Reeb 高度的历史差一个相位；以 $e^{iA_\gamma}$ 为权求和是路径积分的候选"。
于是 AEG 的缝圆 holonomy（Prop 10.7 的一个标量）与那个相位是同一个东西，
扩展只是**把相位换成矩阵**。

## X2 极点：V4 的 K4 障碍绕不开，但可以**分层**

V4 的 K4：把 $1/\sigma$ 放进值层（局部化）会让 $\sigma=0$ 处的谱塌成零环。
V5 又说明角度依赖住在态空间层。两者合起来得到：

$$A(\sigma,\theta)=\frac{1}{\sigma}\cdot F(\theta),\qquad F(\theta)=\text{态空间上的缩并}$$

程序核对：

| 项 | 值 |
|---|---|
| $F$（态空间缩并） | $\tfrac12(1+\cos\theta)$ |
| 留数 $\lim_{\sigma\to0}\sigma A$ | $\tfrac12(1+\cos\theta)$ |
| 有限、且不含 $\sigma$ | ✓ |
| 等于态空间缩并 | ✓ |

**读法**：物理在极点处用的不是"接口的值"，而是**留数**；留数完全有限。
⇒ **K4 的障碍没有被绕开，而是被分层**：值层负责 $1/\sigma$（并在极点上失效），
态空间层负责留数（在极点上良好）。两条读法不竞争，各管各的。

> ⚠️ 这不是"解决了极点"。留数有限是微扰论里把极点因子提出去的结果；
> AEG 若要在 $\sigma=0$ 处**直接用字符读数**，K4 一级成立。

## X3 配对：AEG 已有的"定向相反"获得了内容

AEG 的拼接要求缝的两侧**定向相反**（V1/V2 的 `seam:opposite-orientations`）。
加上态空间之后，那个"相反"正好是配对 $V\otimes V^*\to\mathbb C$ 所需要的东西
—— **扩展不是新加一条要求，而是给已有的一条要求赋予内容。**

| 项 | 值 |
|---|---|
| 光子缝的配对（螺旋度基） | $(+1,+1,-1)$，号差 $(2,1)$ |
| 非退化 | ✓（行列式 $-1$） |
| 三个模全取时的非零振幅数 | **16 / 16** |
| 只取正定部分的非零振幅数 | **4 / 16** |

⇒ **"横模优先" = 取配对的正定部分。这是规范输入**（$+$ 无质量），
**不是从标签或配对推出来的**。上一轮我说"16→4 有一半功劳属于规范"，这里给出了它的形状。

### 一处真实张力与一个可证伪的读法

> 📎 **2026-11-01 更新**：这条张力已在 [`../pants-v7-translation/README.md`](../pants-v7-translation/README.md) §5 解掉——
> 枢纽是"常值边界 **就是** 平凡表示 $j=0$"：两条陈述在说**同一个标签**的两个层，
> 不是关于不同标签的两个断言。下面的原文保留。

**张力**：常值边界封盖阻碍（Thm 10.12 / Cor 10.14）说"正则圆盘不能有常值边界"（不可能）；
而态空间的读法说"收缩一条缝 = 用真空 $\langle0|$ 缩它的边界态，要求标签平凡，贡献 $\dim V_e$"（一个非零常数）。
一个说不可能，一个说等于一个数。

**我的读法（可证伪）**：张力大概是假的，理由与 X2 是同一个分层。
把"封盖"读成态空间上的收缩：代数层 $j=0$ 的缝**可以**被封盖，贡献 $\dim V_e$；
而把它实现成**正则 AES 圆盘**（带度规 $a$ 与 $|da|^2=\mu^2+\lambda^2a^2$）则被 Thm 10.12 挡住。
也就是说 **Thm 10.12 大概是关于解析厚化的阻碍**（Remark 10.8，AEG 自己写着
"a declared structure not yet constructed in general"），而不是关于拓扑/代数接口的阻碍。
若成立，Cor 10.14 应读作"**解析**封盖不可能"。

> **Falsifier**：若把解析数据全部去掉、只留拓扑 + 代数接口，封盖仍然不可能，
> 则这个读法错，Thm 10.12 确实管拓扑层。
