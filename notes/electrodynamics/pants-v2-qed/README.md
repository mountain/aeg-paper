## 0 三句话结论

1. **拓扑层（L1）**：把装饰换成 QED 的（左 pants 2→1 湮灭、右 pants 1→2 产生），
   几何结果与 V1 **逐字段相同**，且与 V1 已存基线**逐字段相同**。
   预期被证实 —— **但这个"证实"是空转的**，理由见第 2 条。
2. **装饰层（L2）**：V1 的几何层**从不读取**输入/输出方向；装饰被一条"冻结字面量"钉住，
   而且它的求值器是**二元的**。⇒ 我上一篇 §7 里写的 falsifier（"若换装饰后秩变了，
   就推翻拓扑无关"）**不可证伪**，因为这段代码里没有东西能"变"。**这条我撤回。**
3. **语义层（L3）**：V1 没有的一层，我补上了：荷/动量守恒、缝上接口状态一致性、
   以及 2→1 的确定性 vs 1→2 的**多重前像**。这一层**能真的拒绝**坏装饰（5/5 负对照被拒），
   并且顺带算出了 M1 缺的那个权重的**定义域**。

## 2 L2 装饰层：V1 的装饰从不进入几何

四条独立发现，全部可执行复现：

| # | 发现 | 证据 |
|---|---|---|
| **a** | **正确的 QED 记录会被挡住** | `rejected: program:frozen-slot-source-contract` —— 程序记录被与一个硬编码字面量**逐字比较** |
| **b** | **荒谬装饰照样通过几何** | 把四个外线端口全算作一个 pants 的输入、并让"缝"由同一个 pants 生出又吃掉，`receive_geometry` 仍然 **accepted**，$\chi(S)=-2$ 不变 |
| **c1** | **四动量取值的接口连摄入都做不到** | 求值器把每个端口读成 `Fraction` ⇒ `ValueError: Invalid literal for Fraction: '[2,2]'` |
| **c2** | **求值器是二元的** | 换成标量值后，1→2 事件在 `environment[event["output"]]` 处 `KeyError: 'output'` |

(c1)+(c2) 合起来是很要紧的一条：**V1 的求值语义里根本没有"一个事件两个输出"的位置**，
而 $e^+e^-\to\mu^+\mu^-$ 的右半（$\gamma\to\mu^+\mu^-$）正是 1→2。

> 📌 V1 自己的 README 已经写了"检查器面向此固定有限合同，不宣称是通用不可信输入验证服务"。
> 本节的四条**不是**在指责它越界，而是把隐含的适用范围**显式化**：
> **V1 验证的是一个冻结对象，不是一类装饰。** 想用"换装饰再跑"去证明装饰无关，跑不出来。

## 3 L3 语义层（V1 没有这一层）：这才是 V2 的真正增量

### 3.1 每个 pants 上的守恒与良构性

| 检查 | 内容 | 结果 |
|---|---|---|
| 端口数 = 3 | AEG Prop 10.2(1)：3 端口 ⇒ pants（2 端口是柱面） | 两个 pants 各 3 ✓ |
| 无别名 | 同一端口不得同时出现两次/两侧 | ✓ |
| 四动量守恒 | $\sum_{\rm in}p-\sum_{\rm out}p=0$，且能量残差非负 | ✓ |
| 电荷守恒 | $\sum_{\rm in}Q-\sum_{\rm out}Q=0$（$e^-\!=\!-1,e^+\!=\!+1,\mu^-\!=\!-1,\mu^+\!=\!+1,\gamma\!=\!0$） | ✓ |
| 缝的接口一致性 | 生产者给出的 $q$ 必须等于消费者吃进的 $q$ | ✓ |

### 3.2 确定性：2→1 是函数，1→2 不是

一维动量格 $k\in[-6,6]$、无质量 $E=|k|$（全部精确有理数）：

| 初态 | 缝上 $q=(E,k)$ | $s=q^2$ | 缝是否在壳 | 在壳拆分 $(k_{\mu^-},k_{\mu^+})$ | 前像数 |
|---|---|---|---|---|---|
| $e^-{=}2,\ e^+{=}-1$ | $(3,1)$ | $8$ | 离壳 | $(-1,2),\ (2,-1)$ | **2** |
| $e^-{=}2,\ e^+{=}3$ | $(5,5)$ | $0$ | **在壳** | $(0,5),(1,4),\dots,(5,0)$ | **6** |

⇒ **1→2 pant 不是确定偏函数**：给定 $q$ 有 2 或 6 组在壳拆分。
它只能被表述成**关系 + 权重**，这与上一篇 §5 的判断一致，现在有了可执行证据。

> 🔧 **一个必要的精确化（防止一句现成的反驳）**：有人会说"外线动量本来就是给定的，
> 于是产生顶点也可以当函数用（给定 $q$ 与 $p_{\mu^-}$，$p_{\mu^+}=q-p_{\mu^-}$）"。
> 这话对，但它恰好说明真实的顶点是**三个端口上的 $\delta$ 关系**，而不是一个函数：
> 三点里知道几个，它就**恰好表现为**函数；$2\to1$ 那一半知道两个所以是函数，
> $1\to2$ 那一半只知道一个所以不是。**"是不是函数"不是顶点的属性，是"已知几个端口"的属性。**
> 这条对 M1 是加强而不是削弱：AEG 里比 gate 更接近顶点的是 **fiber product（关系）**（Prop 10.9），
> 而 $\delta$ 关系的"权重"正是传播子/测度 —— 缺的就是它。

### 3.3 权重必须住在哪：前像集合上的 $(1+\cos^2\theta)$

用 $z=E_{\mu^-}/(E_{\mu^-}+E_{\mu^+})$、$\cos\theta=2z-1$（三维里 $z=\frac{1+\cos\theta}{2}$），
把 QED 的权重 $1+\cos^2\theta$ 逐点算在前像集合上（全部精确有理数）：

| 初态 $e^-{=}2,e^+{=}-1$（$s=8$，离壳） | | | | |
|---|---|---|---|---|
| $z$ | $1/3$ | $2/3$ | | |
| $\cos\theta$ | $-1/3$ | $1/3$ | | |
| $1+\cos^2\theta$ | $10/9$ | $10/9$ | | |
| | **权和 $20/9$** | **常权 $2$** | 峰谷比 **1** | |

| 初态 $e^-{=}2,e^+{=}3$（$s=0$，在壳） | | | | | | | |
|---|---|---|---|---|---|---|---|
| $z$ | 0 | $1/5$ | $2/5$ | $3/5$ | $4/5$ | 1 | |
| $\cos\theta$ | $-1$ | $-3/5$ | $-1/5$ | $1/5$ | $3/5$ | $1$ | |
| $1+\cos^2\theta$ | 2 | $34/25$ | $26/25$ | $26/25$ | $34/25$ | 2 | |
| | **权和 $44/5$** | **常权 $6$** | 峰谷比 $25/13$ | | | | |

> **这就是 M1 的量。** 若 Pant 的拼接只按相等粘（fiber product，不带核），
> 等价于在前像集合上取**常权** ⇒ 预言平的 $\cos\theta$ 分布；而 QED 给 $(1+\cos^2\theta)$，
> 峰谷比 $25/13\approx1.92$。**缺的那个东西，定义域正好是这个前像集合。**
>
> 附带一个自洽性小证据：$s=8$ 那一例只有 2 个拆分，权重**相等**（$10/9$ 各一），
> 因为 $\cos\theta=\mp1/3$ 的平方相同 —— 这正是 $1+\cos^2\theta$ 的前后对称在格点上的样子。

## 5 存疑与边界（不改词）

1. **L1 的几何是 V1 的固定夹具**（两个盒子 + 一根直管），只覆盖这一个有限对象；
   它不是"从 DAG 生成厚化体"的构造器。
2. **L3 的动量模型是一维格点、质量为零**。三维角度只用 $z=(1+\cos\theta)/2$ 的对应关系表述，
   **不是**从三维运动学算出来的。
3. **$s=0$ 那一例的缝在壳**（$[5,5]$ 是类光的），$s=8$ 那一例离壳。这对
   "能不能封盖"（AEG Thm 10.12 / Cor 10.14）是不是对应关系，**我没有推导**，
   只是把两例并列摆出来；$z=0$ 与 $z=1$ 的退化拆分（一条腿能量为零）值得单独看。
4. **L3 只查守恒与确定性，不含任何传播子或振幅**；$(1+\cos^2\theta)$ 是**作为已知的 QED 结果**
   贴到前像集合上的，不是从 Pant 结构推出来的 —— 这一步反过来才是 M1 要解决的问题。
5. `PROGRAM_QED` 里四个外线的"取值"是我手填的记录，只用于展示记录形状；
   真正的运动学在 L3 里由格点算出，两者不联动（这是有意的：V1 的 program 层本来就是记录，不是数值源）。
